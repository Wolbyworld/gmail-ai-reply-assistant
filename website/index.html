Key Features

Generate Full Replies

Press Cmd+Shift+H to open a modal where you enter talking points. The AI reads the email context and generates a complete, professional reply.

Improve Your Text

Select any text and press Cmd+Shift+G. The AI improves grammar, clarity, and tone while keeping your meaning.

Context-Aware

The extension reads the email thread you're replying to, understanding sender, subject, and conversation history.

GPT-5 Powered

Uses OpenAI's latest models (GPT-5, GPT-5-mini) for intelligent, human-like email drafts.

Keyboard-First

No clicking through menus. Just keyboard shortcuts that work instantly. Cmd+Shift+H for replies, Cmd+Shift+G for improvements.

Secure & Private

Runs through the company backend. Your emails are processed securely without storing content.

How It Works

REPLY GENERATION

Generate Complete Replies

Open an email, press the shortcut, enter your key points, and get a full professional reply.

// INCOMING EMAIL
"Hi, can we reschedule our meeting to next week? I have a conflict on Thursday." Press Cmd+Shift+H
// YOUR TALKING POINTS
"yes works for me, suggest tuesday or wednesday afternoon"
// GENERATED REPLY
Hi,

Of course, no problem at all. I'm flexible next week - would Tuesday or Wednesday afternoon work for you? Let me know your preference and I'll send over a calendar invite.

Best regards
TEXT IMPROVEMENT

Polish Your Writing

Select text you've already written and improve it instantly.

// YOUR DRAFT
i think we shoud move forward with the project but we need to make sure the budget is aproved first also the timeline seems tight Select text + Press Cmd+Shift+G
// IMPROVED TEXT
I think we should move forward with the project, but we need to ensure the budget is approved first. Additionally, the timeline seems tight.

Fixed spelling ("shoud" / "aproved")
Added proper punctuation and capitalization
Improved sentence structure
Maintained your original meaning

Installation Guide

Step 0: Download the Extension

Click the button below to download the extension ZIP file.

Download Extension ZIP

Extract the ZIP File

Locate the downloaded ZIP file and extract it to a folder on your computer (remember where you put it!).

Unzip to: ~/Downloads/gmail-ai-reply-assistant/

Open Chrome Extensions

Open Google Chrome and navigate to the extensions page.

Type in address bar: chrome://extensions/

Enable Developer Mode

In the top-right corner of the extensions page, toggle on "Developer mode". This allows you to load unpacked extensions.

Load the Extension

Click "Load unpacked" button (top-left). Navigate to the extracted folder and select the src folder inside it.

Select folder: gmail-ai-reply-assistant/src/

Verify Installation

You should see "Gmail AI Reply Assistant" in your extensions list. The extension icon should appear in your Chrome toolbar.

Look for the extension icon in Chrome toolbar (puzzle piece area)

Open Gmail and Test

Go to Gmail, open any email, click Reply, and press Cmd+Shift+H (Mac) or Ctrl+Shift+H (Windows). A modal should appear for entering your talking points.

Cmd+Shift+H = Generate reply
Cmd+Shift+G = Improve selected text

Troubleshooting

  • Extension not loading? Make sure you selected the src folder, not the parent folder
  • Shortcuts not working? Refresh Gmail after installing. Check chrome://extensions/shortcuts for conflicts
  • Modal not appearing? Make sure you're in a compose window or reply area in Gmail
  • Errors in console? Check the extension's service worker logs at chrome://extensions/ (click "service worker")
